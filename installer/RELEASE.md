## 这是什么

把 DSH 接进微信的单文件安装器。装完就是一套能独立运行的系统：自带微信 4.1.10.27 客户端、Hook 组件、Python/Node 运行时、reader、桥接、控制台。

**不需要预先安装 WeChatAgent。**

## 0.2.0 相对 0.1.1

- **群聊配额**：每小时最多 4 句、两条间隔至少 10 分钟；超了只听不回；被 @ / 拍一拍豁免；私聊不受影响。
- **时间感**：提示词带〔现在〕时钟，历史里隔 30 分钟以上标“X 小时前”，并写明“几小时前是另一段对话”。
- **群对话记录 600 条**（私聊 200），群提示词读到最近 120 条 / 8000 字。
- **@ 只认真实点名**：在 `config.json` 的 `mentionAliases` 里填她自己的微信昵称（默认空 = 不靠正文判断），别人互相 @ 不再把她拽进来。
- **跨会话只带她自己说过的话**，不带对方原话。
- **控制台修复**：日志页不再永远空白；保存允许名单不再杀桥接；“启动全部”用安装目录里的脚本；中文不再乱码。
- **桥接**：白名单外批次打 `[skip]`、启动打印 `[whitelist]`；群批静默窗口 6 秒。
- **安装器**：桥接配置预置群配额；插件配置写入 `groupPerHour` / `groupGapMin`。

## 首次安装必做两步

1. 双击 `WeChatFish-Setup-x64.exe` 安装
2. 双击安装目录里的 `first-run.cmd`，**扫码登录**

微信的数据库密钥只在登录那一刻可用，所以每台新机器都要扫码一次。之后密钥以 DPAPI 加密保存在本机。

## 已知限制

| 限制 | 说明 |
|---|---|
| 首次必须扫码 | 密钥机制决定，无法绕过 |
| 一个账号 | 一个安装实例服务一个微信账号 |
| 封号风险 | 注入违反微信用户协议 |
| 只支持 4.1.10.27 | 微信版本不匹配时 Hook 拒绝加载 |
| Windows only | 依赖 WeChat Windows 客户端 |
