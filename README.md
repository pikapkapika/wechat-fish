# WeChat Fish

把 [DSH](https://github.com/deepseek-ai) 接进微信：她在群里像人一样说话，能看图、认人、挑表情、记得住前几天的事，也知道现在几点。

这不是又一个"自动回复机器人"。该不该回、回什么、发多快，都由 DSH 里的插件决定；这个仓库只负责把"耳朵、嘴和后台"装好。

```
微信客户端 4.1.10.27（自带，已注入 Hook）
   │  本机 HTTP
reader ── 读消息、下载图片和表情（5031）
   │
桥接  ── 攒批、限流、去重、发送、等回执（11232）
   │
DSH 插件 dsh-fish ── 该不该回、怎么回（11231）
```

四层全部走本机回环，不经过任何外部服务器，也不上传聊天记录。

## 仓库结构

| 目录 | 内容 |
|---|---|
| `bridge/` | Node 桥接：SSE 入站 → 攒批 → 调插件 → 原生发送 → 等回执 |
| `plugin/` | DSH 插件 `dsh-fish`（判断、人格、记忆、表情、画图） |
| `installer/` | 安装器脚本与载荷规范（源码；`payload/` 与 `dist/` 不进仓库） |
| `installer/DEPLOY.md` | **给代理读的全自动部署说明**（含版本号、校验、验收） |

## 安装

发布页有单文件安装器 `WeChatFish-Setup-x64.exe`（自带微信客户端与运行时，不需要预装 WeChatAgent）：

1. 运行安装器，装到 `%LOCALAPPDATA%\WeChatFish`
2. 双击安装目录里的 `first-run.cmd`，在弹出的微信窗口里**扫码登录**

微信的数据库密钥只在登录那一刻可用，所以每台新机器都要扫码一次。

要全自动安装（含校验、静默参数、插件挂载、验收），照 `installer/DEPLOY.md` 走。

## 本版（0.2.0）做了什么

- 群聊发言配额：每小时最多 4 句、间隔至少 10 分钟，超了只听不回；被 @ / 拍一拍豁免；私聊不受影响
- 时间感：提示词带当前时钟，历史里隔得久的对话会标「X 小时前」，不会把早上的话题接到下午
- 群对话记录 600 条，群提示词读到最近 120 条
- @ 只认点名（昵称在 `config.json` 的 `mentionAliases` 里配，默认空）
- 跨会话只带她自己说过的话，不带对方原话
- 控制台：日志页修复、保存允许名单不再杀桥接

## 开发

```bash
cd bridge && node --test
cd plugin && node --test
```

桥接与插件都是零依赖（Node 内置模块），测试用 `node:test`。
